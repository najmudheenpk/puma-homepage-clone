# Puma Homepage Clone

A responsive front-end clone of the Puma homepage built using **HTML5** and **CSS3**. This project was created to practice responsive web design, layout structuring, and modern UI development by recreating the look and feel of the official Puma website.

> **Disclaimer:** This project is developed for educational purposes only. It is not affiliated with, endorsed by, or associated with Puma SE.

---

## Live Demo

🌐 https://najmudheenpk.github.io/puma-homepage-clone/


## Features

- Responsive homepage layout
- Modern navigation bar
- Hero banner section
- Featured product section
- Promotional banners
- Responsive design for different screen sizes
- Clean and modern user interface
